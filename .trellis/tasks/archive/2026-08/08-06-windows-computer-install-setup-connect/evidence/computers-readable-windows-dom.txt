连接新电脑
三步把这台电脑接入 SmallKhoj：安装 Aura → 初始化本机 → 连接服务器。

WindowsmacOS / Linux




❶Install（安装）PowerShell
Windows 安装器暂不可用，请稍后重试，或切换到 macOS / Linux。
按 Win + X 选「终端」，或开始菜单搜索 PowerShell；粘贴命令后回车。
看到安装成功输出版本号即完成；失败会给出原因，可重试。


❷Setup（初始化）PowerShell
在同一个窗口继续粘贴执行；只写本机配置和身份，不会连接服务器。
输出 machine ID 和配置路径即完成；重复执行安全。


❸Connect（连接）PowerShell生成连接命令
点击下方按钮生成一次性连接命令（生成后 5 分钟内有效）。
粘贴执行后，状态区会在几秒内显示「已连接」。

完成命令后，这里会显示连接结果。✕
