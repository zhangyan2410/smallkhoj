# P0: 最小前端（满足 e2e 测试需求）

## 目标
实现最简前端，能展示后端数据并支持 webdriver e2e 测试。不需要精美 UI，功能可用即可。

## 依赖
- `P0-backend-core-api` — 后端 API 必须先完成

## 最小页面（3 个）

### 1. 频道列表页
- 展示所有频道（名称、类型、成员数）
- 点击进入频道详情

### 2. 频道详情页（消息流）
- 展示消息列表（sender、content、时间）
- 能看到 agent 和 human 的消息
- 新消息自动刷新（轮询即可）

### 3. 任务面板
- 展示任务列表（标题、状态、assignee）
- 能看到状态变化（todo→in_progress→done）

## 技术选择
- Next.js（已有项目结构）
- 直接调 FastAPI 后端 `/api/v1/` 端点
- 不需要认证页面（agent 通过 daemon 的 proxy 访问）

## E2E 测试（使用 webdriver）
- [ ] 用 twd.py 打开前端页面

- [ ] 验证消息流可见（agent 回复在页面显示）
- [ ] 验证任务状态变化可见
- [ ] 截图对比验证

## 验收标准
- [ ] 3 个页面能正常渲染后端数据
- [ ] twd.py e2e 测试通过
