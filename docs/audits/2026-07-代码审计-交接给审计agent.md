## 4. 两个不可争辩的真实 PostgreSQL RED

### 4.1 Historical seq migration

一次性 PostgreSQL 16 已证明：baseline 表插入 `seq=1,2,3`，执行 advisor 0002 identity
迁移后，identity sequence 仍从 1 开始；第一条省略 seq 的 INSERT 报
`messages_seq_key`，`Key (seq)=(1) already exists`。

永久回归必须覆盖：

- fresh DB；
- baseline-version DB；
- legacy pre-Alembic fingerprint → stamp baseline only → upgrade head；
- 历史显式 seq；
- 过渡窗口旧显式 writer + 新隐式 writer；
- 自动 next value 永远大于所有 committed explicit/historical value；
- FastAPI startup 不运行 create-all/DDL。

禁止使用 `Base.metadata.create_all` 建空表测试来声称迁移正确，也禁止推荐 `stamp head`。

### 4.2 Task DELETE foreign keys

真实 PostgreSQL 按 advisor 路由顺序执行 `DELETE tasks` 后再插入带旧 task_id 的 activity/event，
分别命中 `activity_logs_task_id_fkey` 和 `event_records_task_id_fkey`。事务回滚，Task 仍存在。

终端顺序：

```text
capture primitive tombstone
→ delete dependencies/entity
→ ActivityLog(task_id=NULL, details=tombstone)
→ EventRecord(task_id=NULL, payload.taskId=old UUID, type=task.deleted)
→ commit
→ publish
```

永久测试必须是真实 PostgreSQL route/integration test，并证明 daemon 不把 `task.deleted` 当成
runtime/model work。

## 5. 2026-07-23 要求重做的终端合同（历史需求基线）

这些合同已经指导当前 local candidate 的 schema/auth/runtime/delivery 实现和 focused gates；
保留本节用于最终全量门禁逐项复核，不表示它们仍未开始。

### Auth/tenancy

- backend/frontend/compose/CI/proxy/docs 使用一个 coherent public-key env contract；
- production missing/known default fail closed；
- credential 不进入 query URL；
- missing permissions 明确 default-deny；
- omitted/display/`@handle`/UUID 归一到 canonical actor UUID 后做 self-only authorization；
- two independent transactions 证明最多一个 bootstrap owner；
- global builtin 仅 system/privileged，tenant template 必有 server_id；
- global builtin slug partial unique + `(server_id, slug)` tenant unique；
- legacy NULL 行显式分类，不能静默隐藏；cross-tenant ID 不泄露存在性。

### Runtime/querying

- 50/100-row request 的 whole-request query count 为有名的常数预算；response shape 不变；
- prefetch 使用显式 `_UNSET` 类 sentinel，不能把 `None` 混作“没提供”；
- upload 区分 ingress、Starlette spool、app memory、temporary disk、durable file，并测试失败清理；
- NOTIFY publisher/listener 有 owner、reconnect、generation、bounded shutdown 和 worker connection budget；
- public/agent SSE setup 只留下 frozen primitive claims，不捕获 session/ORM；
- server-wide task/thread 使用 total-order cursor，SQL filter before limit；
- frontend 消费 `nextCursor` 或显示诚实 load-more；
- 一个 account/server browser scope 只开一个 physical SSE connection。

### Delivery/UI

- Ruff baseline 与 production build env 在干净 checkout 上真实绿；
- Bun lockfile/packageManager/README/CI 一致；
- automated flow 创建真实 account/server/membership/session/active-server context；
- 不硬编码 key，不用 query credential；
- Task/File deletion 具有本地化确认、auth、错误回滚和 accessibility；
- repository UI acceptance 使用 `./twd`，不得用 Playwright 替代；
- worktree CWD/branch/URL/ports/DB 与 `smallkhoj-trace` markers 必须记录。
