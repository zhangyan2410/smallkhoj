## 验收标准（写进 prd.md）

1. Runtime 下拉选项来自 daemon 上报的 `detectedRuntimes`，不再写死。
2. 本机未检测到的 runtime（如 codex）**不可选**（灰掉或隐藏），不会出现"选了才报错"。
3. bundled Pi 作为"本机啥都没装时的兜底"恒为可选，且视觉上标识为"自带/不用装"。
4. 选 Pi runtime + 用户自配 key → 能成功创建并启动 agent（本机真测）。
5. 现有 claude_code / codex / custom 路径行为不回归。
6. frontend lint/tsc/build + daemon test/typecheck 全绿。
7. `./twd` 可见证据：引导界面 + 不可选状态 + Pi 自带标识。

## 明确不做（防范围蔓延）

- ❌ 后端 lease / capacity / scoped LLM relay（key 用户自出，不共享后端容量）
- ❌ guide bootstrap / provisioning 权限 / systemRole（单用户）
- ❌ guest role / 邀请机制改造 / 多 guest 共享单 agent（你明确先不做）
- ❌ 空 server 长状态机 / first-run onboarding 长流程（07-22 那套，不在本次范围）
- ❌ 跨平台 embedded Node 打包（07-22 的 distribution 大改，本次 Pi 走用户本机现有 Node 即可，除非真测发现必要再议）
