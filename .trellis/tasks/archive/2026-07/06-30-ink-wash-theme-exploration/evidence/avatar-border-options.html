Agent 头像描边选型

更新后的判断：实际头像组件不是必须是球；静态 demo 里的蓝色圆球是误导。 头像本体应该填满身份框，agent / human 使用同一个 AvatarObject，只是身份框和内容来源不同。

A 当前反例 current / remove
红色印章角标和状态小圆球抢同一个位置。这个后面应该去掉，不作为可选方向。
B 轻身份框 identity-thin
推荐默认方向。只保留轻外框，不再放印章，右上角完整留给状态。
C 账页名签线 ledger
更像登记页上的身份标注。适合成员列表、运行绑定这种偏信息登记的位置。
D 折角纸框 fold
像贴在桌上的小纸框。比印章更轻，也能和便签、任务票据产生区分。
E 内框墨线 brush-line
有一点手工墨线，但不做脏水墨。适合想让 agent 更“活”一点的位置。
F 夹子身份牌 clip
更像被夹住的身份牌。适合未来可拖动/可分配的 agent 实体，不适合所有普通头像。

尺寸对比：推荐 B 在 xs / sm / lg 下保留状态点

agent / human 应该是同一个头像预制体的不同实例

Zed Engine 这里头像是身份锚点，状态点负责表达 agent 当前状态。身份框只负责区分对象类型，不再硬塞印章。
LY
Lee Yan human 也应该走同一个头像预制体，只是 frame 更像签名/名签，不应该变成另一套完全独立的控件。
