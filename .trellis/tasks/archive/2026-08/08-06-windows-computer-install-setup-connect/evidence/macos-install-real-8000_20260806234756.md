## 真实安装命令

使用隔离目录，不触碰 `/Users/lee/.smallkhoj`：

```bash
ROOT=/tmp/REAL_macos-daemon-install-8000_20260806234756.QNhU6y
HOME="$ROOT/home" \
SMALLKHOJ_DAEMON_HOME="$ROOT/daemon-home" \
SMALLKHOJ_DAEMON_BIN_DIR="$ROOT/bin" \
SMALLKHOJ_DAEMON_DOWNLOAD_BASE_URL="http://localhost:8000/downloads/smallkhoj-daemon" \
bash -c 'curl -fsSL http://localhost:8000/downloads/smallkhoj-daemon/install.sh | SMALLKHOJ_DAEMON_DOWNLOAD_BASE_URL="$SMALLKHOJ_DAEMON_DOWNLOAD_BASE_URL" bash'
```
